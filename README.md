# Peptide MALDI imaging
This repository will help you analyse your Matrix-assited laser desorption ionisation (MALDI) imaging dataset created on a TIMS-TOF flex instrument. Specifically this code helps you analyse your imaging parallel reaction monitoring  parallel accumulation-serial fragmentation (iprm-PASEF) datasets targetting peptides. After the iprm-PASEF measurement the MS/MS spectra of the targeted peptides are detangeled by their ionmobility traces in Data Analysis resulting in a .mgf file for each peptide. Those .mgf files can be analysed using MASCOT. The resulting peptide identities can be coroborated using the provided exemplary jupyter notebook:

This script is designed to coroborate MS/MS spectra of peptides measured with iprm-PASE and their theoretical identities obtained by MASCOT. It calculates the theoretical masses of the peptide identities and its fragment ions, matches them with experimental data, and visualizes the results. It is written in python and uses jupyter notebook for interactive analysis. The user needs to provide the theoretical peptide sequence, the experimental MS/MS spectrum (as .mgf or .tsv file), and tolerance for matching. The script will output the calculated theoretical masses, matched fragment ions, and a plot of the MS/MS spectrum of the experimental data with annotated matched theoretical peaks. If user input is required, it will be indicated in the comments. The script is designed to be flexible and can handle different peptide sequences and modifications.
